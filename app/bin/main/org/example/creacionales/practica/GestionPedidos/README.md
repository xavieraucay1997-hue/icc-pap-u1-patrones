## Singleton - 

Se creo este patron para la clase ConfiguracionSitema para que todos los pedidos usen una misma configuracion del impuesto de 15%, asi se evita crear varios objetos y ademas podemos modificar el porcentaje desde esta misma clase ConfiguracionSistema. 
 
## Factory Method

Se utilizo este metodo ya que es muy bueno para crear los diferentes tipos de pedidos de esta practica que son los rpecenciales o en linea sin tener que crear los objetos directamente en la parte principal, asi organizamos mejor el codigo y es mas facil de crear nuevos tipos de pedidos
